# Vivaan Kaushik — Portfolio

A responsive, dependency-free portfolio for Vivaan Kaushik's work in technical product management and AI.

## Preview

From this directory, run `python3 -m http.server 8000`, then open `http://localhost:8000`.

## Files

- `index.html`: semantic content, navigation, project summaries, and metadata.
- `styles.css`: responsive layouts, visual design, reduced-motion and print styles.
- `script.js`: optional active-navigation state and current footer year.
- `portfolio.jpeg`: portrait.
- `resume.pdf`: current resume, updated September 2026.
- `favicon.svg`: site icon.

No build process, package installation, API keys, or runtime CDN is required. The site remains usable without JavaScript. Publish from the repository root using GitHub Pages.

## Content updates

Edit the HTML directly. Keep experience dates and impact metrics aligned with the resume; replace `resume.pdf` when updating it. The Blue Street Data workflow illustration is conceptual, not an actual product screenshot. Update canonical and Open Graph URLs if moving to a custom domain.
